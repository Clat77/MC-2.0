## 📂 Onde encontrar os dados (Data Map)

Para editar as configurações do jogo manualmente, procure nestes arquivos:

### 🎭 Eventos e Punições
* **Caminho:** `frontend/src/data/events.js`
* **O que tem:** Lista de eventos aleatórios, descrições, severidade e punições.

### ⚙️ Dados Gerais do Jogo
* **Caminho:** `frontend/src/data/constants.js`
* **O que tem:**
    * Manchetes de Jornal (News)
    * Lista de Táticas (Formações)
    * Ligas e Times iniciais
